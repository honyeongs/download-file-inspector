# Download File Inspector

[웹에서 바로 사용](https://download-inspector-web.yao0422q.chatgpt.site/) · [Windows 앱 설치와 웹 실행 안내](docs/WEBSITE.md)

최근 검사: [대표 10개·전체 회귀·웹 테스트 공개 기록](docs/testing/README.md). 원본 개인정보와 비밀값은 포함하지 않습니다.

다운로드한 파일을 **열기 전에** 로컬에서 검사하는 보안 포트폴리오 프로젝트입니다.
SHA-256 원본 대조와 ZIP 메타데이터 위험 탐지를 분리합니다. 기존 네트워크 분석기와 독립된 저장소입니다.

**백신이 아닙니다. 안전한 파일이라는 인증을 제공하지 않습니다.**
URL에서 파일을 미리 내려받거나 다운로드를 가로채는 프로그램도 아닙니다.

## 실행

Python 3.11 이상이 필요합니다. 외부 API 키와 런타임 패키지는 필요하지 않습니다.

```powershell
python run.py serve
```

브라우저에서 `http://127.0.0.1:8893/`에 접속합니다. Windows에서는 `Start-Inspector.cmd`도 사용할 수 있습니다.
포트를 사용 중이면 `python run.py serve --port 8894`처럼 변경합니다.
파일 선택 또는 드롭 후, 신뢰하는 배포처의 SHA-256을 선택적으로 입력하고 검사합니다.
보고서 저장 버튼은 JSON을 사용자 컴퓨터에 명시적으로 내려받습니다.

```powershell
python run.py inspect "release.zip"
python run.py inspect "release.zip" --sha256 <배포처의_64자리_SHA256> --output report.json
python run.py hash "release.zip"
```

`--output`은 새 파일만 생성합니다. 기존 파일·심볼릭 링크·입력 파일을 덮어쓰지 않습니다.
설치형 CLI는 `python -m pip install .` 후 `download-inspector`로 실행합니다.

## 결과 해석

- **기준값 일치:** 제공한 SHA-256과 같은 바이트입니다. 기준값의 출처를 인증하지는 않습니다.
- **기준값 불일치:** 기준 파일과 다릅니다. 변조, 전송 오류, 버전 차이 등을 구분하지는 못합니다.
- **판단 불가:** 신뢰할 원본 기준값이 없습니다. 검사한 파일의 해시를 다시 입력하는 것은 원본 검증이 아닙니다.
- **위험 징후:** 실행 확장자·시그니처, 위장 확장자, 제어 문자, ZIP 경로 탈출, 특수 파일, 중복·충돌 이름, 중첩 압축, 암호화, 압축 폭탄 징후, 로컬·중앙 헤더 불일치 등을 탐지합니다.
- **발견된 징후 없음:** 검사한 규칙에서 징후를 찾지 못했습니다. 안전하다는 의미가 아닙니다.
- **ZIP 메타데이터 확인:** 구조와 선언값을 확인했습니다. 압축된 파일 내용·실제 CRC·내부 악성코드는 검사하지 않았습니다.

CLI 종료 코드: `0` 검사 완료 및 높은 징후 없음, `1` 해시 불일치 또는 높은 징후,
`2` 입력·읽기·출력 오류, `3` ZIP 손상·지원 불가·한도 초과로 검사 미완료입니다. `3`이 `1`보다 우선합니다.
`0` 역시 안전 판정이 아닙니다.

## 검사 한도

- 입력 64 MiB, 중앙 디렉터리 1 MiB, ZIP 항목 3,000개, 보고서 위험 징후 표시 500개.
- 선언된 개별 파일 128 MiB, 전체 512 MiB 초과 또는 높은 압축률은 위험 징후로 표시합니다.
- 압축 해제, 파일 실행, 비밀번호 해제, 재귀 압축 검사, 자동 다운로드, 외부 전송을 하지 않습니다.
- ZIP64 중앙 디렉터리·분할 ZIP은 미지원으로 표시합니다. RAR·7z·TAR 등의 내부 분석은 하지 않습니다.
- 확장자와 파일 형식 확인은 얕은 시그니처 검사입니다. 문서 매크로·PDF 동작·디지털 서명을 분석하지 않습니다.
- 압축 데이터 자체의 변조는 메타데이터가 그대로라면 놓칠 수 있습니다. 신뢰할 전체 파일 해시가 필요합니다.

## 저작권과 배포

애플리케이션 코드는 이 프로젝트를 위해 새로 작성했습니다. 화면의 Lucide 아이콘은 원본 라이선스를 함께 제공합니다.
저장소 공개 자체와 별개로, 자체 코드의 재사용·상업 배포 라이선스는 소유자가 결정해야 합니다.
현재 자체 코드에 오픈소스 라이선스를 부여하지 않았습니다. 판매 전 라이선스·개인정보·약관 검토는 별도로 필요하며,
이 프로젝트의 점검은 법률 자문이나 법적 적합성 보증이 아닙니다.
