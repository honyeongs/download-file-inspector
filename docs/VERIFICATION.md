# 검증 기록

## 로컬 검증 환경

2026-10-12, Windows, Python 3.14, Chromium / Playwright 1.64.0.
실제 악성 파일 없이 합성 ZIP과 임시 텍스트 파일로 확인했다.
단위·HTTP 테스트 57개: 56개 통과, Windows 심볼릭 링크 권한으로 1개 건너뜀.
이 중 메타데이터 변이 테스트는 고정 시드로 500개 변형을 추가 검사한다.

## 확인한 동작

- SHA-256 일치·불일치·기준 없음, 잘못된 해시, 동일 바이트 스냅샷, 입력 크기 제한.
- ZIP 경로 탈출, Windows 경로·스트림·예약 이름, 위장 확장자, 중첩 압축, 매크로 확장자.
- 암호화 표시, 심볼릭 링크, 이름 충돌, 선언 크기·압축률, 헤더 불일치, 잘못된 UTF-8.
- 중앙 디렉터리 크기·항목 수 제한, 분할 ZIP·ZIP64 미지원, ZIP 손상 상태.
- 압축 내용 읽기·추출 API를 호출하지 않음. 압축 데이터 변경은 CRC 미검사로 유지됨.
- CLI JSON 생성, 입력·기존 보고서 덮어쓰기 거부, 절대 로컬 경로 보고서 제외.
- HTTP Host·Origin·형식·크기·길이 검증, 경로 탈출 방지, CSP·nosniff·캐시 금지.
- 실제 브라우저 파일 선택 -> 해시 입력 -> 검사 -> 위험 목록 -> ZIP 검색 -> JSON 저장 -> 초기화.
- 1440px, 390px, 360px 화면에서 가로 넘침·이미지 누락·파일명 HTML 실행 없음. 화면 캡처를 직접 확인함.
- 검사 취소·재검사, 기준 없는 텍스트 파일 검사, 해시 불일치 표시.

## 보안 점검 범위

Bandit 1.9.4로 `src` 정적 분석: 경고 0개. 이것은 취약점 부재나 침투 테스트 완료를 뜻하지 않는다.
런타임 의존 패키지가 없지만 Python·브라우저 자체와 개발 도구의 취약점까지 없다는 의미는 아니다.
현재 보안 경계와 잔여 위험은 `SECURITY.md` 및 `THREAT_MODEL.md`에 명시했다.

Windows에서 심볼릭 링크 생성 권한이 없는 경우 관련 테스트 하나를 건너뛴다.
Linux·다른 Python 버전과 공개 원격 CI 결과는 저장소 Actions에서 별도로 확인할 수 있다.
로컬 성공을 원격 CI 성공으로 대신 주장하지 않는다.

## 라이선스 점검 범위

외부 UI 자산은 Lucide 아이콘 4개이며 원본 라이선스 고지를 동봉했다.
기존 분석기 코드는 복제하지 않았고, 실제 악성코드·타인 파일·비밀정보를 배포하지 않는다.
자체 코드의 오픈소스 라이선스 선택과 판매 전 법률 검토는 아직 별도 작업이다.
